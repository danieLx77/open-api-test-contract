REFERÊNCIA DA INVESTIGAÇÃO

Contrato OpenAPI

Produto:
  type: object
  required:
    - id
    - nome
    - preco
    - disponivel
  properties:
    id:
      type: integer
    nome:
      type: string
      minLength: 1
    preco:
      type: number
      minimum: 0
    disponivel:
      type: boolean
  • id número inteiro obrigatório
  • nome texto obrigatório, com pelo menos um caractere
  • preco número obrigatório, maior ou igual a zero
  • disponivel booleano obrigatório: true ou false

O contrato não define additionalProperties: false; propriedades adicionais são aceitas por este schema.
